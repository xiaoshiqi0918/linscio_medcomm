# 参赛图文写作能力 — 初步方案（v0.1）

> 文档性质：产品/体验向初步方案，供内部评审与迭代；不含开发排期与接口细节。

## 1. 背景与目标

面向健康科普类「图文参赛」场景：需文图结合、总篇幅常为千字级，配图数量多；版式与提交格式随各届赛事通知变化。

### 核心目标（本期）

1. **先能完成合规投稿**：文稿结构 + 插图位 + 导出 Word/PDF，配图格式与命名符合常见通知要求。
2. **降低插图门槛**：在每处配图提供画意说明、中英双语文生图提示词、风格预设、负向/安全提示；用户可复制到任意绘图工具生成，**不必依赖内置绘图 API 即可完成参赛**。
3. **赛制不写死**：不在产品内预设某一场官方规则；以用户上传当届《比赛公告》后解析或手工勾选约束为主，适配多届、多主办单位。

## 2. 设计原则

| 原则 | 说明 |
|------|------|
| **公告为真** | 字数上限、字体、文件格式、命名规则等以「上传的公告」提炼为准；默认值仅作无公告时的弱提示。 |
| **结构与引擎解耦** | 文稿块、画意、中英文提示词为结构化数据；未来接入任一绘图 API 或 Comfy 云端部署，仅需替换「执行出图」一步。 |
| **科普责任边界** | 插图明示为辅助理解；非诊断与解剖确权依据；文案与图示说明中保留免责声明占位。 |

## 3. 用户与典型场景

- **参赛者**：医务工作者或科普作者，需在有限时间内形成千字内图文。
- **典型路径**：选择或建立文章结构 → 填写正文与分块 → 每块填写画意与中英提示 → 站外生成或上传 JPG → 套用模板导出 Word/PDF → 按要求命名投递。

## 4. 功能范围（一期）

### 4.1 文章与章节（用户自选）

- 支持自定义章节层级（可提供引言 / 问题 / 知识点 / 误区 / 建议 / 结尾等模版供选用，但不强制）。
- 千字级总字数统计（可选：是否计入标题、图注、参考文献 — **由当届赛制配置决定**；无公告时使用产品默认）。

### 4.2 赛制配置（不写死场次）

- 支持上传官方通知（PDF / 图片 / Word）。
- **赛制参数**可由运营或用户勾选，或经轻量解析填入，例如：正文字数上限、是否要求 Word+PDF、正文字体、配图格式（如 JPG）、文件命名模板、截止日期等。
- 文稿侧展示「当前文稿适用：未绑定赛事 / 某赛事（自拟名）」。

### 4.3 插图与绘图指引（一期重点）

每一块（或每一段）图示区域包含：

- **画意（1 句）**：本图要传达什么；忌空泛表述。
- **画幅建议**：如横版 16:9、1:1 等（与 Word 占位框对齐）。
- **风格预设（少而全）**：如信息图 / 流程示意 / 轻漫画叙事 / 隐喻场景等；每档绑定固定中英文提示模版（占位符可由正文或用户填写替换）。
- **中英文提示词双栏**：
  - **上栏：中文** — 主编辑区，符合中文叙述习惯。
  - **下栏：英文** — 默认供复制到站外文生图工具。
  - **中文变更后**：经防抖（如 500～800ms）将整段译为英文并更新下栏。
  - **下栏可直接手改**；若与自动译文并存，默认不因手改英文而覆盖中文，并提供 **「按当前中文重新翻译英文」**。
- **负向与安全提示**：单独可复制区块，降低畸形、水印、过激画面等风险。
- **操作指引**：复制英文 → 在所用工具中选相同比例 → 导出 JPG → 回填本块。

### 4.4 图源类型

- **本地上传**（手绘或外部软件导出 JPG）为必选能力。
- **AI 生成**：一期为「站外生成 + 本地上传」；二期再接统一绘图引擎（API / 自建等）。

### 4.5 导出与排版

- 导出 Word、PDF。
- 支持与赛制绑定的排版预设（如仿宋三号等），以「赛制包」或「导出主题」形式选用。
- 配图嵌入与文件命名：按赛制模板生成默认文件名（如「单位-科室-第一作者-作品名」），用户可修改。

## 5. 明确不在一期（可并行预研）

- 内置端到端一键出图（对接 Comfy Cloud、腾讯云 GPU、或其他云 API）。
- 全自动从正文生成全部提示词（可做辅助提示，不作为一期必达）。
- 「科普演讲赛」等与图文赛道并列的整条能力（可数据结构预留）。

## 6. 数据与合规要点（方案层）

- **模型与版权**：站外 AI 绘图由用户自担所选工具条款；产品侧可提供商用风险提示与模型许可说明（对内维护白名单）。
- **隐私**：公告与稿件中的个人信息遵循平台隐私策略（存储范围、期限见隐私政策）。

## 7. 成功标准（一期）

1. 用户仅凭本功能即可完成：章节自选 → 千字内成稿 → 每图有清晰中英提示与风格 → JPG 就位 → Word/PDF 导出 → 合规命名。
2. 用户体感：未必懂 prompt 工程，按界面即可完成配图准备。
3. 赛制变更时：主要通过上传公告或改参数适配，不要求为某一届单独发版固化规则。

## 8. 待决议题（下一轮）

1. 「英文跟随中文」：手改英文后，是否在单独操作下反向更新中文（当前建议：**默认单向 + 一键重译**）。
2. 赛制参数：初期纯手工勾选 vs 先做 PDF 结构化抽取（影响工期）。
3. 翻译：首期仅用通用机器翻译，还是叠加「医学术语自定义表」。
