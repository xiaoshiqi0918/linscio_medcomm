# 已否决方案清单

> **用途**：新人入职第一天必读，避免重复发起已经讨论过的方案。
> **维护规则**：每次否决一个方案，把"为什么不做"写清楚。如果未来情况变化要重新启动，更新本文件并标注启动条件。

---

## 1. 自训练 7B 改写器（基于 Qwen / DeepSeek LoRA）

**否决日期**：2026-05-01

**为什么提出**：通用大模型成本和延迟相对高，理论上小模型微调能更便宜更快。

**为什么不做**：
- 短期 ROI 低：现在每篇改写成本几分钱，延迟 10-30 秒可接受
- 缺前置数据：没有"用户接受 vs 拒绝改写"的标注数据，无法做 RLHF/DPO
- 缺微调 pipeline：从模型选型、训练、部署、监控到迭代，整条链路要从 0 搭
- 不是真正瓶颈：现在的瓶颈是检测器和事实保护，不是改写器成本

**重新启动条件**：
- 日生成量稳定 ≥ 5 万篇，规模效应开始显现
- 用户行为埋点（[v1.1 P2-3](../AIGC治理可执行方案_v1.1.md#p2-3-用户反馈与-diff-沉淀机制v11-新增项)）累积 ≥ 10 万条 diff 数据
- 内部已有 1-2 名能做模型微调的工程师

## 2. 用医学专用模型替换通用大模型（百川医疗 / MedGPT）

**否决日期**：2026-05-01

**为什么提出**："通用大模型在医学场景事实错误率高，专用模型应该更准。"

**为什么不做**：
- 我们是 **RAG 架构**：每篇生成都注入最新的 PubMed 文献，事实准确性来自检索而非参数记忆
- 医学专用模型训练数据 cutoff 通常较早，**指南、新药信息滞后**
- 医学专用模型的"幻觉"风险并不显著低于通用大模型 + RAG
- 替换成本高：现有 prompt 工程围绕通用大模型调优，换模型要重做

**重新启动条件**：
- 国内出现训练数据 cutoff ≤ 6 个月的医学专用模型
- 公开评测显示在我们的具体任务（医学科普长文生成）上明显优于通用大模型
- 我们的 RAG 召回质量上限已经被压榨完毕，但事实错误率仍 ≥ 5%

## 3. Grammarly 半自动逐句确认形态

**否决日期**：2026-05-01

**为什么提出**："改写不要自动执行，让用户一键采纳/拒绝每条建议，类似 Grammarly。"

**为什么不做**：
- 偏离核心用户需求：医生 / 编辑 / 医学传播者要的是"快速可发布稿"，不是"逐句修改"
- 降低产品价值：当前一键生成可发布稿是核心卖点，半自动会让用户感觉"还不如自己写"
- 段落级 [AI 优化] 标记 + diff 入口（[v1.1 P1-3](../AIGC治理可执行方案_v1.1.md#p1-3-段落-ai-优化-标记--diff-入口产品价值最高项建议提速)）已经提供了透明度，不需要走完全半自动

**重新启动条件**：
- 用户调研明确显示"宁可逐句改也不要黑盒"的用户占比 ≥ 30%
- 出现明显竞品采用 Grammarly 形态并获得高满意度

## 4. 实时 PPL / LLM 判别器

**否决日期**：2026-05-01

**为什么提出**：用语言模型计算困惑度（PPL）或调 LLM 做"AI vs 人"判别，作为检测层增强。

**为什么不做**：
- 检测层已经够准：当前规则 + 段落统计的检测器三档区分度 30/74/100，已能区分清洁/中等/重 AI 味
- 实时 PPL 需要中文语言模型推理，部署和成本压力大
- 实时 LLM 判别器增加同步延迟 3-5 秒，影响"一键成文"体验
- 边际收益不明：再加 10 分准确度，但牺牲明显的延迟和成本

**保留口子**：
- 用 LLM 判别器做**周期性离线评测**（每周抽样 100 篇，用 GPT-4o 或 Claude 跑判断），作为线上检测器准确率的**外部基准线**
- 这不算"做"，是定期监控，不影响线上性能

**重新启动条件**：
- 离线 LLM 判别器与线上检测器的相关性 < 0.5（说明检测器失效）
- 用户反馈"AI 味检测不准"的负反馈占比 ≥ 20%

## 5. 把"医学空洞度低"自动触发改写器补充信息

**否决日期**：2026-05-01

**为什么提出**：检测器发现段落空洞（没有具体数字 / 专有名词 / 时间锚点 / 限定人群），自动让改写器补充信息让段落更"实"。

**为什么不做**（违反原则 1 + 原则 3）：
- 改写器没有真实事实来源，会**编造数据**
- 编造的医学数据是产品的死亡按钮：法律风险 + 信任崩塌
- 正确做法：检测器只展示给用户看，让用户去补充真实信息

**注意**：本项不是"暂时不做"，而是**永远不做**。如果未来要让改写器"补内容"，必须先有可信的医学知识库（指南库 / UpToDate 等）作为事实来源，且必须强制标注引用。
