# 检验科基础知识库

> 面向科普写作智能体的事实参考库 —— 所有参考范围基于中国卫生行业标准（WS/T系列），供写作时调用核实

---

## 一、检验科概况与基本概念

### 1.1 检验科的亚专业分组

| 分组 | 主要检测内容 | 典型检测项目 |
|------|-----------|------------|
| 临床生化 | 血清/血浆中的化学成分 | 肝功能、肾功能、血糖、血脂、电解质、心肌标志物 |
| 临床血液学 | 血细胞计数和形态、凝血功能 | 血常规、凝血四项、D-二聚体、骨髓细胞学 |
| 临床免疫学 | 抗原抗体反应、免疫功能 | 乙肝五项、HIV抗体、甲功五项、肿瘤标志物、自身抗体 |
| 临床微生物学 | 病原微生物鉴定和药敏 | 血培养、尿培养、痰培养、药敏试验 |
| 临床体液学 | 尿液、粪便、脑脊液等体液分析 | 尿常规、粪常规+隐血、脑脊液常规生化 |
| 临床分子诊断 | 核酸检测 | 病原体PCR、基因突变检测、HBV-DNA定量 |
| 输血科/血库 | 血型鉴定、交叉配血 | ABO血型、Rh血型、不规则抗体筛查 |

### 1.2 科普写作中必须理解的核心概念

**参考范围（参考区间）：** 不是"正常"与"异常"的分界线。它的定义是——健康参考人群中，中间95%的人的检测结果所覆盖的范围。这意味着即使完全健康的人，也有5%的概率某项结果落在参考范围之外。

**临床决定限：** 与参考范围不同，临床决定限是基于临床结局设定的阈值。例如空腹血糖≥7.0 mmol/L诊断糖尿病——这不是统计学概念，而是基于该阈值以上人群视网膜病变风险急剧增加的临床证据。

**灵敏度（Sensitivity）：** 有病的人中，检测结果为阳性的比例。灵敏度高=漏诊少。

**特异度（Specificity）：** 没病的人中，检测结果为阴性的比例。特异度高=误诊少。

**阳性预测值（PPV）：** 检测结果为阳性的人中，真正有病的比例。受患病率影响极大——在低患病率人群中筛查，即使试剂很准，阳性结果也可能大多数是假阳性。

**科普要点：** "检查阳性≠有病"和"检查阴性≠没病"是检验科普最核心的认知框架。灵敏度和特异度是试剂本身的性能指标，但一个人拿到阳性报告后"自己到底有没有病"，取决于阳性预测值，而这和患病率密切相关。

### 1.3 常见检测干扰因素

| 干扰因素 | 影响机制 | 受影响的常见项目 |
|---------|---------|---------------|
| 溶血 | 红细胞破裂释放胞内物质 | 钾假性升高、LDH假性升高、AST假性升高、胆红素测定干扰 |
| 脂血（乳糜） | 脂质微粒导致光散射 | 所有比色法项目均可能受影响 |
| 黄疸（高胆红素） | 胆红素的颜色干扰比色法 | 肌酐（Jaffe法假性降低）、尿酸等 |
| 生物素 | 干扰含生物素-链霉亲和素系统的免疫检测 | 甲功、心肌标志物、肿瘤标志物（详见第九节） |
| 嗜异性抗体/HAMA | 人体内的异种抗体桥连检测试剂 | 所有夹心法免疫检测均可能受影响 |
| 类风湿因子（RF） | 高浓度RF可干扰免疫检测 | 部分免疫检测项目假阳性 |
| 药物 | 直接化学干扰或代谢产物干扰 | 维生素C干扰尿糖试纸，头孢类干扰Jaffe法肌酐 |
| 采血条件 | 止血带过紧、溶血、标本放置过久 | 钾、乳酸、血糖（放置后下降） |

**数据来源：** WS/T 225-2024《临床化学检验血液标本的采集与处理》; Kabiri P et al., J Clin Lab Anal 2021;35(9):e23940（生物素干扰）

## 二、血常规（全血细胞计数，CBC）

### 2.1 主要项目与参考范围

| 项目 | 缩写 | 参考范围（成人） | 临床意义 |
|------|------|-------------|---------|
| 白细胞计数 | WBC | 3.5-9.5 ×10⁹/L | 升高→感染、炎症、白血病；降低→病毒感染、药物、再障 |
| 中性粒细胞比例 | NEUT% | 40-75% | 细菌感染时通常升高 |
| 淋巴细胞比例 | LYMPH% | 20-50% | 病毒感染时常相对或绝对升高 |
| 红细胞计数 | RBC | 男 4.3-5.8 ×10¹²/L；女 3.8-5.1 ×10¹²/L | 降低→贫血 |
| 血红蛋白 | Hb/HGB | 男 130-175 g/L；女 115-150 g/L | 贫血诊断的核心指标 |
| 红细胞压积 | HCT | 男 0.40-0.50；女 0.35-0.45 | 反映红细胞在血液中的体积占比 |
| 平均红细胞体积 | MCV | 82-100 fL | <82→小细胞性贫血（缺铁）；>100→大细胞性贫血（缺B12/叶酸） |
| 血小板计数 | PLT | 125-350 ×10⁹/L | 降低→出血风险；升高→血栓风险或反应性增多 |
| C反应蛋白 | CRP | <10 mg/L（部分实验室<5 mg/L） | 非特异性炎症标志物，细菌感染时显著升高 |

**参考范围来源：** WS/T 405-2012《血细胞分析参考区间》

### 2.2 科普写作要点

- 血常规是最常见、最基础的检查，几乎所有住院和多数门诊患者都会查
- "白细胞高=有炎症"是过度简化——剧烈运动、情绪激动、妊娠、糖皮质激素用药等均可导致WBC一过性升高
- 贫血的诊断看血红蛋白（Hb），不是红细胞计数。WHO标准：成年男性Hb<130 g/L，非妊娠女性Hb<120 g/L即为贫血
- 血小板低≠一定会出血。临床上PLT>50×10⁹/L时一般不会自发出血；PLT>100×10⁹/L可耐受手术
- CRP升高没有特异性——感染、创伤、手术、自身免疫病、肿瘤等都可以升高

### 2.3 常见误区

| 误区 | 事实 |
|------|------|
| "白细胞高就是细菌感染，要吃抗生素" | 白细胞升高原因众多，需结合中性粒细胞比例、CRP、PCT和临床表现综合判断 |
| "体检血常规都正常就是健康" | 血常规正常不能排除很多疾病（如早期肿瘤、肝肾功能异常、血脂异常等） |
| "血小板低就是白血病" | 血小板减少最常见的原因是免疫性血小板减少症（ITP），不是白血病 |

## 三、肝功能检查

### 3.1 主要项目与参考范围

| 项目 | 缩写 | 参考范围 | 临床意义 |
|------|------|---------|---------|
| 丙氨酸氨基转移酶 | ALT(GPT) | 男 9-50 U/L；女 7-40 U/L | 肝细胞损伤最敏感的指标，肝炎、药物性肝损伤时显著升高 |
| 天冬氨酸氨基转移酶 | AST(GOT) | 15-40 U/L | 肝细胞和心肌细胞均含有，也见于心梗 |
| γ-谷氨酰转移酶 | GGT | 男 10-60 U/L；女 7-45 U/L | 胆汁淤积和酒精性肝病时升高，饮酒后可一过性升高 |
| 碱性磷酸酶 | ALP | 45-125 U/L | 胆汁淤积、骨病时升高；儿童和青少年生长期可生理性升高 |
| 总胆红素 | TBIL | 3.4-17.1 μmol/L | 升高→黄疸（溶血性/肝细胞性/梗阻性） |
| 直接胆红素 | DBIL | 0-6.8 μmol/L | 直接胆红素为主的升高→梗阻性黄疸 |
| 总蛋白 | TP | 65-85 g/L | |
| 白蛋白 | ALB | 40-55 g/L | 降低→慢性肝病、营养不良、肾病综合征、大量失血 |
| 球蛋白 | GLB | 20-40 g/L | 升高→慢性感染、自身免疫病、多发性骨髓瘤 |

**参考范围来源：** WS/T 404系列标准（各部分）；《全国临床检验操作规程》第4版

### 3.2 转氨酶升高的分级解读

| ALT水平 | 可能原因 |
|---------|---------|
| 轻度升高（<3倍正常上限） | 脂肪肝（最常见）、药物、饮酒、轻度病毒性肝炎 |
| 中度升高（3-10倍） | 急慢性肝炎、药物性肝损伤、自身免疫性肝炎 |
| 重度升高（>10倍，常>500 U/L） | 急性病毒性肝炎、药物或毒物中毒、缺血性肝损伤 |
| 极度升高（>1000 U/L） | 急性肝坏死（药物中毒如对乙酰氨基酚、急性重型肝炎） |

### 3.3 科普写作要点

- 体检中最常见的转氨酶轻度升高原因是**非酒精性脂肪性肝病（NAFLD）**，而非病毒性肝炎
- ALT和AST的比值有诊断意义：ALT>AST多见于慢性肝炎/脂肪肝；AST>ALT（尤其AST/ALT>2）提示酒精性肝病或肝硬化
- 转氨酶正常不等于肝脏正常——肝硬化晚期肝细胞大量坏死后，转氨酶反而可以不高甚至偏低（因为能释放酶的肝细胞已经很少了）
- 白蛋白是肝脏合成功能的重要指标，半衰期约21天，因此急性肝损伤时白蛋白可能还正常，慢性肝病时才会明显下降
- 体检发现GGT单独升高最常见的原因是饮酒，其次是脂肪肝和药物

## 四、肾功能检查

### 4.1 主要项目与参考范围

| 项目 | 缩写 | 参考范围 | 临床意义 |
|------|------|---------|---------|
| 血清肌酐 | Cr/SCr | 男 57-97 μmol/L；女 41-73 μmol/L | 反映肾小球滤过功能，升高提示肾功能下降 |
| 血尿素氮 | BUN | 2.9-8.2 mmol/L | 受饮食（高蛋白）和脱水影响大，特异性不如肌酐 |
| 尿酸 | UA | 男 208-428 μmol/L；女 155-357 μmol/L | 升高→痛风风险、肾结石风险、代谢综合征 |
| 胱抑素C | CysC | 0.51-1.09 mg/L（方法依赖） | 比肌酐更早反映肾功能变化，不受肌肉量和饮食影响 |
| 估算肾小球滤过率 | eGFR | ≥90 mL/min/1.73m² | 肾功能分期的核心指标 |

### 4.2 慢性肾脏病（CKD）分期

| 分期 | eGFR（mL/min/1.73m²） | 含义 |
|------|----------------------|------|
| G1 | ≥90 | 肾功能正常（但可能有蛋白尿等肾损伤证据） |
| G2 | 60-89 | 轻度下降 |
| G3a | 45-59 | 轻到中度下降 |
| G3b | 30-44 | 中到重度下降 |
| G4 | 15-29 | 重度下降 |
| G5 | <15 | 肾衰竭（可能需要透析或移植） |

### 4.3 科普写作要点

- 肌酐的"盲区"：肾功能丢失约50%以上时，血肌酐才开始明显升高。因此肌酐正常不代表肾功能完全正常。eGFR比单看肌酐更灵敏
- 肌酐受肌肉量影响：健身者/肌肉发达者肌酐可能偏高但肾功能正常；老年消瘦者肌酐可能在"正常范围"但实际eGFR已下降
- 体检发现尿酸高≠痛风。高尿酸血症的定义是男性>420 μmol/L、女性>360 μmol/L，但仅约5-12%的高尿酸血症患者会发展为痛风
- BUN升高的最常见原因不是肾病，而是脱水和高蛋白饮食

## 五、血糖与糖尿病相关检查

### 5.1 诊断标准（中国2型糖尿病防治指南 2020年版）

| 指标 | 正常 | 糖尿病前期 | 糖尿病 |
|------|------|----------|--------|
| 空腹血糖（FPG） | <6.1 mmol/L | 6.1-6.9 mmol/L（空腹血糖受损，IFG） | ≥7.0 mmol/L |
| OGTT 2h血糖 | <7.8 mmol/L | 7.8-11.0 mmol/L（糖耐量减低，IGT） | ≥11.1 mmol/L |
| 随机血糖 | — | — | ≥11.1 mmol/L（伴典型症状） |
| HbA1c（糖化血红蛋白） | <6.0% | 6.0-6.4%（参考） | ≥6.5%（可辅助诊断） |

### 5.2 糖化血红蛋白（HbA1c）

- 反映过去 **2-3个月** 的平均血糖水平（基于红细胞约120天寿命）
- 不受单次空腹、进餐、运动等短期因素影响
- 控制目标：大多数2型糖尿病患者 **<7.0%**，老年/合并症多者可放宽至<8.0%，年轻/新诊断者可争取<6.5%
- 局限性：溶血性贫血、大量失血、妊娠等影响红细胞寿命的情况下HbA1c不可靠
- HbA1c每降低1%，微血管并发症风险降低约37%（UKPDS研究）

### 5.3 科普写作要点

- 空腹血糖要求禁食 **8-12小时**（不是越长越好，禁食超过16小时可能因应激反应导致血糖升高）
- 单次空腹血糖≥7.0不能直接诊断糖尿病——需要两次不同日检测均达标，或一次血糖达标+伴有典型症状（多饮多尿多食消瘦）
- "餐后血糖"在早期糖尿病筛查中往往比空腹血糖更敏感——很多糖尿病前期患者空腹血糖正常但OGTT 2h血糖已异常
- 糖化血红蛋白是监控达标的"金标准"，但不能替代日常血糖监测（因为它反映的是平均值，掩盖了血糖波动）

## 六、血脂检查

### 6.1 主要项目与参考范围

| 项目 | 理想水平 | 边缘升高 | 升高 |
|------|---------|---------|------|
| 总胆固醇（TC） | <5.2 mmol/L | 5.2-6.2 mmol/L | ≥6.2 mmol/L |
| LDL-C | <3.4 mmol/L | 3.4-4.1 mmol/L | ≥4.1 mmol/L |
| HDL-C | ≥1.0 mmol/L | — | <1.0为降低 |
| 甘油三酯（TG） | <1.7 mmol/L | 1.7-2.3 mmol/L | ≥2.3 mmol/L |

**来源：** 《中国成人血脂异常防治指南（2016年修订版）》

### 6.2 科普写作要点

- 血脂检查要求 **禁食12小时** 以上采血（主要影响TG，TC和LDL-C受进食影响较小）
- 近年有研究和部分国际指南（如2016年欧洲指南）开始支持非空腹血脂检查也有临床价值，但中国目前仍推荐空腹
- 家族性高胆固醇血症（FH）患者LDL-C可>5 mmol/L甚至>8 mmol/L，这类患者即使年轻、体瘦也需要药物治疗
- TG>5.6 mmol/L时需要警惕急性胰腺炎风险
- "化验单上胆固醇正常不等于安全"——对于已有冠心病的患者，LDL-C的目标是<1.8 mmol/L，远低于一般参考范围的上限

## 七、甲状腺功能检查

### 7.1 甲功五项

| 项目 | 缩写 | 参考范围（方法和试剂依赖） | 临床意义 |
|------|------|------------------------|---------|
| 促甲状腺激素 | TSH | 0.27-4.2 mIU/L | 最敏感的甲状腺功能筛查指标 |
| 游离T4 | FT4 | 12-22 pmol/L | 反映甲状腺激素的实际活性水平 |
| 游离T3 | FT3 | 3.1-6.8 pmol/L | T3是生物活性最强的甲状腺激素 |
| 总T4 | TT4 | 66-181 nmol/L | 受甲状腺结合球蛋白（TBG）影响，妊娠期升高 |
| 总T3 | TT3 | 1.3-3.1 nmol/L | 同上 |

**注意：** 各实验室的参考范围因检测系统不同而有差异，以报告单上标注的参考范围为准。

### 7.2 常见甲功模式解读

| TSH | FT4 | FT3 | 最可能的诊断 |
|-----|-----|-----|------------|
| ↓↓ | ↑ | ↑ | 甲亢（Graves病最常见） |
| ↑↑ | ↓ | ↓或正常 | 甲减 |
| ↑ | 正常 | 正常 | 亚临床甲减（TSH 4.2-10 mIU/L，争议最大） |
| ↓ | 正常 | 正常 | 亚临床甲亢 |
| ↑↑ | ↑ | ↑ | TSH分泌性垂体瘤（罕见）或甲状腺激素抵抗 |

### 7.3 甲状腺抗体

| 抗体 | 缩写 | 临床意义 |
|------|------|---------|
| 甲状腺过氧化物酶抗体 | TPOAb | 桥本甲状腺炎的标志性抗体，阳性率约90% |
| 甲状腺球蛋白抗体 | TgAb | 桥本甲状腺炎，也影响Tg的检测准确性 |
| 促甲状腺激素受体抗体 | TRAb | Graves病（甲亢）的特异性抗体 |

### 7.4 科普写作要点

- TSH和甲状腺激素是"翘翘板"关系——甲亢时TSH被抑制（低），甲减时TSH被刺激（高）
- 体检发现TSH轻度升高（4.2-10 mIU/L）、FT4正常=亚临床甲减。是否需要治疗存在争议，不是所有人都需要补甲状腺素
- TPOAb阳性≠甲减。约10-15%的健康人群TPOAb阳性，大多数不发展为甲减，但需要随访
- 妊娠期的甲功参考范围与非妊娠人群不同，特别是TSH——妊娠早期TSH正常上限约为4.0 mIU/L（部分指南建议2.5），需使用妊娠期特异性参考范围
- 甲功检查是**生物素干扰的重灾区**——服用生物素补充剂可导致夹心法检测的TSH假性降低和竞争法检测的FT4/FT3假性升高，模拟甲亢的结果模式

## 八、肿瘤标志物

### 8.1 常用肿瘤标志物

| 标志物 | 参考上限 | 相关肿瘤 | 重要说明 |
|--------|---------|---------|---------|
| AFP（甲胎蛋白） | <20 ng/mL | 肝细胞癌 | 也在妊娠期升高、急慢性肝炎时轻度升高 |
| CEA（癌胚抗原） | <5 ng/mL | 结直肠癌、肺癌、胃癌等多种 | 吸烟者可升高至10 ng/mL，特异性差 |
| CA125 | <35 U/mL | 卵巢癌 | 子宫内膜异位症、月经期、妊娠、腹水等均可升高 |
| CA19-9 | <37 U/mL | 胰腺癌、胆管癌 | Lewis血型阴性者（约5-10%人群）不产生CA19-9，检测永远为阴性 |
| CA15-3 | <31.3 U/mL | 乳腺癌 | 早期乳腺癌敏感性低（<30%），主要用于治疗后监测 |
| PSA（前列腺特异抗原） | <4 ng/mL（年龄分层见下） | 前列腺癌 | 前列腺增生、前列腺炎、骑自行车、直肠指检后均可升高 |
| NSE（神经元特异性烯醇化酶） | <16.3 ng/mL | 小细胞肺癌、神经母细胞瘤 | 溶血严重影响结果（红细胞含NSE） |
| CYFRA21-1 | <3.3 ng/mL | 非小细胞肺癌 | |
| SCC（鳞状细胞癌抗原） | <1.5 ng/mL | 鳞状细胞癌（宫颈、肺、食管等） | 皮肤病（银屑病、湿疹）可导致升高 |

### 8.2 PSA的年龄分层参考值

| 年龄 | PSA参考上限 |
|------|-----------|
| 40-49岁 | <2.5 ng/mL |
| 50-59岁 | <3.5 ng/mL |
| 60-69岁 | <4.5 ng/mL |
| ≥70岁 | <6.5 ng/mL |

PSA 4-10 ng/mL为"灰区"，需结合游离PSA/总PSA比值（fPSA/tPSA<0.16提示恶性可能大）和前列腺MRI进一步判断。

### 8.3 科普写作中最重要的原则

**肿瘤标志物不能用于健康人群的癌症筛查（AFP用于肝癌高危人群除外）。** 原因：

1. 大多数肿瘤标志物的灵敏度和特异度都不够高，用于健康人群筛查时假阳性率极高
2. 很多良性疾病也会导致肿瘤标志物升高（如CEA在吸烟者中、CA125在月经期）
3. 肿瘤标志物正常不能排除肿瘤——早期肿瘤时标志物往往不升高
4. 肿瘤标志物的主要价值在于：已确诊肿瘤患者的疗效监测和复发监测

**"体检加查一套肿瘤标志物"** 是中国体检行业普遍存在的过度检查现象。2019年中国抗癌协会发布的《中国肿瘤标志物临床应用专家共识》明确指出：不推荐对无症状健康人群进行肿瘤标志物的普遍筛查。

## 九、免疫检测方法学与干扰（科普写作的技术基础）

### 9.1 两大类免疫检测方法

| | 夹心法 | 竞争法 |
|---|-------|--------|
| 原理 | 两个抗体"夹住"目标物质 | 标记物和目标物质竞争结合位点 |
| 信号与浓度关系 | 正相关（浓度越高信号越强） | 负相关（浓度越高信号越弱） |
| 适用 | 大分子（TSH、胰岛素、HCG等） | 小分子（FT4、FT3、皮质醇等） |
| 生物素干扰方向 | 假性降低 | 假性升高 |

### 9.2 生物素干扰详解

**为什么生物素会干扰？** 很多现代免疫检测（尤其是Roche电化学发光平台）使用生物素-链霉亲和素系统作为信号放大和捕获工具。当患者血液中有高浓度游离生物素时，它会与试剂中的链霉亲和素竞争结合，干扰检测信号。

**哪些人血液生物素可能偏高？**
- 服用生物素补充剂者（美发美甲保健品常含5-10mg/片，是每日推荐量30μg的166-333倍）
- 血液透析患者（透析液可含生物素，肾脏清除减少）
- ICU重症患者
- 使用含生物素的肠外营养患者

**受影响的常见项目：**
- 甲功：TSH假性降低，FT4/FT3假性升高→模拟甲亢
- 心脏标志物：肌钙蛋白假性降低→可能掩盖心梗
- 肿瘤标志物：部分假性降低（夹心法）或假性升高（竞争法）
- HCG：假性降低→可能影响妊娠诊断

**处理建议：**
- 化验前至少停服生物素补充剂 **72小时**（FDA建议）
- 高剂量使用者（>5mg/天）建议停服 **1周**
- 临床结果与症状不符时，应考虑生物素干扰并换用不含生物素-链霉亲和素系统的检测平台复查

**数据来源：** FDA Safety Communication 2017; Chiu KC et al., Pract Lab Med 2025;45:e00472; Rosner I et al., Cureus 2019, DOI:10.7759/cureus.5470

### 9.3 钩状效应（Hook Effect）

当目标物质浓度极高时，夹心法检测可能出现假性降低甚至假阴性——过量的抗原同时占据了捕获抗体和检测抗体，阻止了"夹心"结构的形成。

常见场景：HCG极高的葡萄胎/绒癌，AFP极高的大肝癌。解决方法：标本稀释后重新检测。

## 十、凝血功能检查

### 10.1 凝血四项

| 项目 | 参考范围 | 临床意义 |
|------|---------|---------|
| 凝血酶原时间（PT） | 11-14秒 | 反映外源性凝血途径，华法林监测指标 |
| 国际标准化比值（INR） | 0.8-1.2 | PT的标准化表达，华法林治疗目标通常2.0-3.0 |
| 活化部分凝血活酶时间（APTT） | 25-37秒 | 反映内源性凝血途径，肝素监测指标 |
| 凝血酶时间（TT） | 14-21秒 | 延长→肝素、纤维蛋白原降低、FDP增多 |
| 纤维蛋白原（FIB） | 2.0-4.0 g/L | 降低→DIC、严重肝病；升高→急性炎症 |

### 10.2 D-二聚体

- 参考范围：<0.5 mg/L FEU（或<250 ng/mL DDU，注意单位不同）
- 临床价值：**阴性排除价值高**——D-二聚体正常可以基本排除深静脉血栓（DVT）和肺栓塞（PE）
- 局限：阳性特异性差——手术后、创伤、感染、妊娠、肿瘤、高龄等均可升高
- 年龄校正：>50岁者建议使用年龄×10 μg/L作为阈值（如60岁用600 μg/L），可减少假阳性

### 10.3 科普写作要点

- 术前常规查凝血四项是为了评估出血风险
- PT/INR延长最常见原因：华法林抗凝治疗、维生素K缺乏、肝功能严重受损
- APTT延长最常见原因：肝素治疗、血友病（Ⅷ或Ⅸ因子缺乏）、狼疮抗凝物（这种情况APTT延长但实际是高凝状态，非常反直觉）
- D-二聚体不能用于"确诊"血栓，只能用于"排除"血栓

## 十一、尿液检查

### 11.1 尿常规主要项目

| 项目 | 正常结果 | 异常的常见意义 |
|------|---------|-------------|
| 尿蛋白（PRO） | 阴性或微量 | 阳性→肾小球/肾小管损伤、泌尿道感染、剧烈运动后一过性 |
| 尿糖（GLU） | 阴性 | 阳性→血糖超过肾糖阈（约10 mmol/L），也见于肾性糖尿 |
| 尿潜血（BLD） | 阴性 | 阳性→血尿（泌尿系结石、肿瘤、肾炎、感染） |
| 尿白细胞（WBC） | 阴性或少量 | 增多→泌尿道感染 |
| 尿亚硝酸盐（NIT） | 阴性 | 阳性→提示细菌感染（革兰阴性菌为主） |
| 尿酮体（KET） | 阴性 | 阳性→糖尿病酮症、饥饿、剧烈运动 |
| 尿比重（SG） | 1.003-1.030 | 偏低→尿崩症、大量饮水；偏高→脱水、糖尿 |
| 尿pH | 4.5-8.0 | 酸性偏向→高蛋白饮食、代谢性酸中毒；碱性偏向→泌尿道感染（变形杆菌）、素食 |

### 11.2 科普写作要点

- 尿蛋白一次阳性不等于肾病——发热、剧烈运动、直立体位（体位性蛋白尿，多见于青少年）均可导致一过性蛋白尿，需要复查
- 尿潜血阳性≠血尿。试纸法检测的是血红蛋白的过氧化物酶活性，维生素C大量摄入可导致假阴性，某些消毒剂可导致假阳性。需要离心后镜检红细胞来确认
- 尿液标本采集对结果影响很大：最佳标本是**清洁中段尿**（排尿中间段接取）、**晨起首次尿**（浓缩度最高，检出率最高）
- 女性月经期不宜做尿常规（经血污染导致假阳性）

## 十二、感染相关检查

### 12.1 常用感染标志物对比

| 标志物 | 升高时间 | 峰值时间 | 特点 |
|--------|---------|---------|------|
| WBC/中性粒细胞 | 数小时 | 1-2天 | 非特异性，应激、药物也可导致升高 |
| CRP | 6-8小时 | 48小时 | 非特异性炎症指标，细菌和自身免疫病均升高 |
| PCT（降钙素原） | 2-4小时 | 24小时 | 对细菌感染较特异，用于指导抗生素的启停 |
| IL-6 | 1-2小时 | 6小时 | 最早升高的炎症因子，新生儿败血症早期诊断 |
| ESR（血沉） | 缓慢 | 数天 | 非特异性，变化滞后，受贫血和球蛋白影响大 |

### 12.2 PCT（降钙素原）的临床应用

| PCT水平 | 临床解读 |
|---------|---------|
| <0.1 ng/mL | 细菌感染可能性极低，一般不建议使用抗生素 |
| 0.1-0.25 ng/mL | 细菌感染可能性低，非必要不使用抗生素 |
| 0.25-0.5 ng/mL | 可能存在局部细菌感染，酌情使用抗生素 |
| 0.5-2 ng/mL | 细菌感染可能，建议抗生素治疗 |
| 2-10 ng/mL | 全身细菌感染，脓毒症可能 |
| >10 ng/mL | 严重脓毒症/脓毒性休克 |

### 12.3 乙肝五项（乙肝两对半）

| 项目 | 缩写 | 阳性含义 |
|------|------|---------|
| 乙肝表面抗原 | HBsAg | 感染HBV的标志（现症感染） |
| 乙肝表面抗体 | HBsAb(Anti-HBs) | 保护性抗体（接种疫苗成功或感染恢复） |
| 乙肝e抗原 | HBeAg | 病毒复制活跃的标志 |
| 乙肝e抗体 | HBeAb(Anti-HBe) | 病毒复制减弱（但不是没有） |
| 乙肝核心抗体 | HBcAb(Anti-HBc) | 既往或现症感染的标志（终生阳性） |

**常见组合模式：**
- "大三阳"：HBsAg(+)、HBeAg(+)、HBcAb(+)→ 病毒复制活跃
- "小三阳"：HBsAg(+)、HBeAb(+)、HBcAb(+)→ 病毒复制相对减弱，但不代表无传染性
- 仅HBsAb(+)→ 最理想的状态，说明疫苗接种成功有保护力
- HBsAb(+) + HBcAb(+)→ 既往感染已恢复并获得免疫

### 12.4 科普写作要点

- "大三阳比小三阳严重"是过度简化。关键看HBV-DNA病毒载量和肝功能，而非单看"几阳"。有些小三阳患者HBV-DNA很高、肝损伤严重
- HBsAb≥10 mIU/mL视为有保护力。成人接种乙肝疫苗后约5-15%无应答（不产生抗体），需加强接种
- 乙肝不通过共餐传播——传播途径是血液、性接触和母婴垂直传播

## 十三、标本采集的关键知识

### 13.1 各类标本的采集要求

| 采血管颜色/添加剂 | 检测用途 | 标本类型 |
|-----------------|---------|---------|
| 红色/黄色（无抗凝剂或促凝剂） | 生化、免疫、肿瘤标志物 | 血清 |
| 紫色（EDTA-K2） | 血常规、糖化血红蛋白 | 全血/血浆 |
| 蓝色（枸橼酸钠 109mmol/L，1:9） | 凝血功能 | 血浆（采血量必须准确，抗凝剂比例严格） |
| 绿色（肝素锂） | 急诊生化 | 血浆 |
| 灰色（氟化钠-草酸钾） | 血糖 | 血浆（氟化钠抑制糖酵解，防止血糖假性下降） |
| 黑色（枸橼酸钠 1:4） | 血沉 | 全血 |

### 13.2 影响检验结果的常见采集问题

| 问题 | 后果 | 预防措施 |
|------|------|---------|
| 止血带绑扎时间过长（>1min） | 钾、乳酸、蛋白质假性升高 | 找到血管后立即松开止血带，绑扎不超过1分钟 |
| 从输液同侧手臂采血 | 电解质、血糖等被输液液体稀释 | 必须从非输液侧肢体采血 |
| 标本溶血 | 钾、LDH、AST假性升高 | 避免细针抽血、过度震荡、注射器直喷入管 |
| 标本放置过久未送检 | 血糖下降（约每小时5-7%）、钾升高 | 采血后30分钟内送检；血糖标本用灰头管 |
| 凝血管采血量不准确 | PT、APTT结果不可靠 | 蓝头管必须采至刻度线（血液:抗凝剂=9:1），不足或过多均需重采 |

## 十四、科普写作中的常见数据陷阱

1. **"化验结果不在参考范围内就是有病"——这是最大的误解。** 参考范围覆盖的是健康人群中间95%的数据，5%的健康人结果天然在范围外。体检时查20个项目，统计上至少有1个"异常"几乎是必然的
2. **"某项指标升高XX倍很严重"——需要看是什么指标。** ALT升高10倍（500 U/L）确实提示严重肝损伤，但CRP升高10倍（50 mg/L）可能只是一次普通感冒
3. **"灵敏度99%的检测阳性了，我有99%的概率有病"——这是对灵敏度的根本误解。** 如果疾病患病率是1/1000，即使灵敏度99%、特异度99%，1000人中检测阳性者约11人（1个真阳性+10个假阳性），你"真有病"的概率只有约9%
4. **肿瘤标志物的参考范围≠安全线。** CA125从15升到30（都在参考范围内）的变化趋势，可能比单次测量35（略超参考上限）更有意义
5. **不同医院的检验结果可能不能直接比较。** 不同检测系统（不同厂家的仪器和试剂）的结果存在系统偏差。特别是免疫检测项目（甲功、肿瘤标志物等），不同平台间差异可达10-30%。监测同一指标的变化趋势应尽量在同一家医院完成
