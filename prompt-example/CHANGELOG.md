# Prompt 优化变更日志（Layer 0 + Layer 1）

> 本文档记录 prompt 架构的设计决策和变更理由，供后续维护和跨团队沟通参考。

---

## 一、Layer 0：从三份文档合并为一份

### 合并了什么
原 system prompt（17条规则）+ writing_sop_core（九大原则+质量红线+证据引用+受众适配+格式风格）+ anti_hallucination 中的通用规则（规则一数据禁造、规则三绝对化禁止、规则四来源标注、规则六症状免责、占位符规范）

### 消解的冲突

| 冲突点 | 原状态 | 优化后 |
|-------|-------|-------|
| 用药剂量 | system说"加免责"、sop说"绝对禁止"、anti说"不得推荐" | 统一为：具体药物+剂量+用法的组合=绝对禁止；单独提及药物类别=允许+加免责 |
| 证据语言 | 三套体系（六级/四级/禁止词） | 统一为一张六级表，每级同时标明"允许用词"和"严禁用词"，双向锁定 |
| 来源标注 | "可自然归属" vs "不得标注" 矛盾 | 统一为：允许自然语言归属（"研究发现"），禁止具体引用标注（"据《XX指南》"）；两者的区别用示例明确 |
| 待补充标签 | 三处定义，触发条件不同 | 统一为一处定义+统一触发条件+描述规范 |
| 模板化套话 | sop禁止套话 vs anti规则六要求固定免责句 | 免责语义必须存在，但措辞可灵活调整，不要求固定句式 |

### 新增内容

| 新增项 | 原因 |
|-------|------|
| 第0节·身份锚定 | 原来只有一句"你是医学科普写作助手"，无法在弱模型上建立稳定人格 |
| 第1节·边界情况裁决 | 原来四分类有灰色地带（文献中的教科书知识标什么？），新增三条裁决规则 |
| 第2节·严禁向上越级 | 原来只说了"应该用什么"，没说"不能用什么"，弱模型会越级 |
| 第3.2节·急症识别、特殊人群 | 原安全红线只覆盖5类场景，新增2类高危场景 |
| 第6.2节·反AI腔调 | 原Layer 0完全没有风格负面约束，"人味"控制缺位 |
| 第6.3节·正面风格锚定 | 给模型一个"像谁在说话"的人格锚点 |
| 第7节·冲突裁决说明 | 九大原则原来只有排序没有裁决规则 |
| 第8节·层间优先级 | 原来声明"不可覆盖"但没有执行机制 |

### 删除/下移内容

| 删除项 | 原因 |
|-------|------|
| sop第四节·受众适配 | 应由风格注册表动态注入，不在Layer 0写死四种受众 |
| sop第五节·叙事科普数据 | "播放量2.6倍"等数据可能被模型引用到正文，删除数据只保留指令 |
| anti_hallucination规则五·10个比喻示例 | 保留3个最典型的在Layer 0，其余下移到Part 1 few-shot |
| [推断:基于XX]标签 | 要求模型自行推断并标注推断来源，实测执行率低且风险高；改为"不得自行推断，用待补充占位" |

## 二、Layer 1 儿童受众 — 变更说明

| 变更 | 原因 |
|------|------|
| 增加分龄锚定（默认6-8岁） | 原3-12岁跨度太大，输出无法稳定 |
| 句长从硬数字改为"一次呼吸能念完"+上限15字 | 纯数字约束跨模型执行率低 |
| 放宽因果连接词禁令 | 原来完全禁止"因为/所以"，但6-8岁可以理解简单因果 |
| 新增"可能被儿童模仿"禁止项 | 原来只有视觉恐吓禁止，缺少行为诱导风险约束 |
| 新增风格锚定示例 | 原来"像讲故事"太模糊，不同模型理解不同 |

## 三、Layer 1 脚本类 — 变更说明

| 变更 | 原因 |
|------|------|
| 新增患者角色台词约束 | 原来只约束医生台词，患者台词的隐性医疗建议风险未覆盖 |
| 新增视觉文字（字幕/标注）约束 | 原来只约束口播，画面文字可绕过 |
| 新增结尾情绪基调规则 | 原来只禁止虚假承诺文案，但画面情绪暗示同样会误导 |
| 医生台词从示例扩展为禁止清单+参考方向 | 原来只有示例，弱模型无法泛化 |

## 四、Layer 1 图示类 — 变更说明

| 变更 | 原因 |
|------|------|
| 明确画面描述字段使用英文 | 原规则用英文示例但未声明语言要求 |
| 拟人化检验改为引用Layer 0三步法+追加图示专属要求 | 原来与anti_hallucination的比喻检验重复且粒度不同 |
| 新增流程图/机制图约束 | 原规则缺失，但这是图示类的高频内容类型 |
| 新增数据可视化例外规则 | 原"不含数值"与趋势图需要数值的需求冲突 |
| 儿童绘本视觉安全改为引用式 | 原来与children_patch完全重复，改为引用避免维护不一致 |
| "示意图"标注增加执行位置说明 | 原来没指定标注出现在哪里 |

## 五、跨模型加固措施汇总

| 措施 | 适用位置 | 解决什么问题 |
|------|---------|-------------|
| 否定句→正面指令 | 全局 | 否定句式在弱模型上遵守率低 |
| 每条禁止规则配"应该怎么做" | Layer 0 §3, Layer 1 全部 | 模型知道不做什么但不知道做什么时，会自己发明 |
| 证据语言表格化+双向锁定 | Layer 0 §2 | 原来只规定"应该用"，没规定"不能用"，模型会越级 |
| 模糊判断条件→具体清单 | Layer 0 §3.1, §6.2 | "可能引起恐慌"等主观判断不同模型阈值差异大 |
| 示例区前加"仅供学习"声明 | Layer 0 §4.4 | 部分模型会把示例格式（❌/✅）带入输出 |
| 层间优先级裁决机制 | Layer 0 §8 | 声明"不可覆盖"但无执行机制时，模型会被下游层指令覆盖 |
