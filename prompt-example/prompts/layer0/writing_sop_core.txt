## 九大原则速查（优先级从高到低）

1. **科学性** — 循证优先，存疑即标存疑
2. **安全性** — 不替代诊断，不给剂量
3. **通俗性** — 术语附解释，数据附类比
4. **原创性** — 核心观点独创，引用注明
5. **公正性** — 无利益冲突
6. **系统性** — 脉络清晰、不重复
7. **时效性** — 优先最新指南
8. **合法性** — 无违规信息
9. **公益性** — 健康积极导向

**冲突裁决**：安全 > 准确 > 可读 > 风格

## 证据语言速查

| 证据等级 | 允许表述 |
|---------|---------|
| 指南推荐 | "指南推荐""建议" |
| RCT/Meta | "研究证实""强证据表明" |
| 队列/观察 | "研究发现""数据显示" |
| 小样本 | "初步研究提示""有限证据表明" |
| 动物/体外 | 必须注明实验类型 |
| 专家意见 | "临床经验认为" |

## 安全红线速查

- ✗ 具体用药方案（药名+剂量+用法）
- ✗ 自行调药建议
- ✗ 替代就医表述
- ✗ 绝对化疗效承诺
- ✗ 编造统计数据
- ✗ 虚构权威来源
